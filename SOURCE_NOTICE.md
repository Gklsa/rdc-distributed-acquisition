# Source attribution

This repository contains a curated source export of a ROS 2 distributed sensor-acquisition project. Existing package metadata and in-file authorship notices are retained.

The six ROS packages (`rdc_bringup`, `rdc_core`, `mocked_sensors_cpp`, `mocked_sensors_py`, `ti_tmp116`, `ti_tmp116_py`) declare `Apache-2.0` in their manifests. Component-level notices continue to apply; this document does not assign a new license to the entire repository or claim sole authorship.

The README, generic configuration templates and local launch helpers describe how to inspect and use the exported source. Site-specific settings and experimental recordings are supplied by the user.
